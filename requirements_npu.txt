# UniSHARP portable Ascend NPU training environment (Linux only)
#
# This file is for scripts/train_npu_portable.sh and
# scripts/train_npu_portable_ddp.sh.  Those scripts use the standard-PyTorch
# portable renderer; they do NOT use gsplat, CUDA, Triton, 3DGEER, or the CUDA
# KNN extension listed in requirements.txt.
#
# ---------------------------------------------------------------------------
# System prerequisites — install these BEFORE pip, not through this file.
# ---------------------------------------------------------------------------
# 1. Huawei Ascend driver + firmware for the target accelerator (for example,
#    Ascend 910/910B), installed by the host administrator.
# 2. CANN toolkit/runtime compatible with both the driver and torch_npu.
# 3. Linux x86_64 or aarch64, a supported CPython release (Python 3.10 is the
#    tested baseline for this project), and a C++ build toolchain for packages
#    that need one.
# 4. In every training shell, initialise CANN first, for example:
#      source /usr/local/Ascend/ascend-toolkit/set_env.sh
#    Use the actual set_env.sh path of the installed CANN release.
#
# The PyTorch, torchvision and torch_npu versions are a matched three-way
# combination with CANN. Do NOT install CUDA PyTorch on this host and do NOT
# blindly install the newest torch_npu wheel. Select the exact versions from
# the Ascend compatibility matrix, then install them BEFORE the packages
# below. Example only (replace with your verified matched versions):
#
#   pip install torch==<TORCH_VERSION> torchvision==<TORCHVISION_VERSION>
#   pip install /path/to/torch_npu-<MATCHED_VERSION>-linux_<ARCH>.whl
#
# Keep these three lines commented: a pinned version here would be wrong for
# any host using another CANN release.
# torch==<MATCHED_TORCH_VERSION>
# torchvision==<MATCHED_TORCHVISION_VERSION>
# torch_npu==<MATCHED_TORCH_NPU_VERSION>
